# Positive-Technologies

SPA приложение управления инцидентами безопасности.

## Архитектура решения

- `frontend/` — Angular 21 standalone-компоненты.
- `backend/` — Express.js моковый сервер с CRUD API и SSE-потоком уведомлений.
- `docker-compose.yml` — запускает frontend и backend вместе.

### Ключевые технологии

- Angular 21 + standalone components
- Angular Material для форм, таблиц, диалогов и уведомлений
- RxJS + signals для фронтенд-стора
- Express + SSE для бэкенд-уведомлений
- Docker Compose для быстрой локальной сборки и запуска

## Запуск проекта

### Локально

1. Открой терминал в корне проекта.
2. Запусти бэкенд:
   ```bash
   cd backend
   npm install
   npm start
   ```
3. Запусти фронтенд в другом терминале:
   ```bash
   cd frontend
   npm install
   npm start
   ```
4. Открой в браузере `http://localhost:4200`

### Через Docker Compose

1. Убедись, что Docker установлен.
2. Выполни в корне проекта:
   ```bash
   docker compose up --build
   ```
3. Перейди в браузер по адресу `http://localhost:4200`

## Что работает

- Lazy-loading списка инцидентов с пагинацией.
- Выбор видимых колонок в таблице.
- Фильтрация и сортировка по полям.
- Сайд-панель с детальной информацией об инциденте.
- Создание, правка и удаление инцидентов через диалог.
- Реактивная форма с `mat-select`, датами, тумблерами и валидацией.
- Секция уведомлений с реальным временем и toast-сообщениями.
- Обработка ошибок при запросах к бэкенду.

## Примечания по качеству

- Формы реализованы на Reactive Forms с валидацией.
- CRUD-операции работают через единую сервисную прослойку.
- SSE-поток уведомлений показывает toast-уведомления и список сообщений.
- Docker Compose поднимает frontend и backend без дополнительных действий.
